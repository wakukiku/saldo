# SALDO

SALDO — адаптивное веб-приложение для учёта личных финансов. Я делал этот проект как полноценный интерактивный интерфейс: операции можно добавлять, редактировать и удалять, показатели пересчитываются на основе данных выбранного месяца, а изменения сохраняются между сессиями.

## Что реализовано

- главная страница со сводкой по балансу, доходам и расходам;
- список операций с добавлением, редактированием и удалением;
- статистика и графики по выбранному периоду;
- бюджеты по категориям с отображением прогресса;
- учёт подписок и финансовых целей;
- переключение между месяцами;
- хранение пользовательских данных в `localStorage`;
- адаптивная навигация для десктопа и мобильных устройств;
- ленивое подключение страниц через `React.lazy`.

## Структура проекта

```text
src/
├── main.tsx      # приложение, роутинг и основная навигация
├── pages.tsx     # страницы и графики
├── editors.tsx   # формы и панели редактирования
├── store.ts      # состояние и работа с данными
├── ui.tsx        # переиспользуемые UI-компоненты
└── styles.css    # стили приложения
```

## Локальный запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

## Данные

Проект работает без собственного backend: демонстрационные данные и изменения пользователя хранятся локально в браузере. Это позволяет показать основную логику интерфейса без подключения внешнего API или базы данных.
